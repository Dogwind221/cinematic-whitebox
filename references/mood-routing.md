# 意境到白模镜头

适用：剧本出现风、重逢、回眸、等待、告别等意象，或虽无这些词但行动与关系变化相符。默认以《繁花》的框景、关系距离、局部光影和反应停留组织镜头；本参考补充具体节拍，不替换全片摄影方案。

来源是“美学自习室｜情绪与美”合集的 124 条目录快照，入口 [BV19T421v7q6](https://www.bilibili.com/video/BV19T421v7q6/)。逐集跨全时长抽样观察，重点另做连续时间采样；不是逐帧精读或完整对白转写。标题用于检索，画面观察用于支持构图，下面的白模设计是独立推导。逐条标题、时间码和适用限制见 [mood-source-index.md](mood-source-index.md)。不将混剪中的不同电影拼称同一个连续场景。

## 先判语义，再选镜头

1. 引用当前剧本场次/段落，提取环境事实、人物目标、关系起点与终点。将意象标为**实景、比喻、引用、否定、回忆/梦境**；回忆同时注明所属时间层。
2. 确定观众要看到的变化。例如“重逢却装作陌生”是认出后回避；“等风来”可能是真实等待起风，也可能只是一句比喻，需查上下文。“风头”“风格”不建立风力场，“心里下雨”不建立雨，“没能重逢”不安排两人见面。
3. 以叙事需要选择一个主意境，必要时加一个兼容的环境辅意象。优先复用已有窗、走廊、衣摆、道具；不得为了套参考新增人物、关系、年代、天气或结局。没有合适意境时回到常规剧情分镜。
4. 按下表检索，再在来源索引中找到具体画面证据。相同构图出现在多条混剪中只算一种方法；演员、国别、性别、外貌和标题中的角色标签不构成摄影参数或道德判断。
5. 写出可播放的状态变化。实际动作不支持运镜时用固定机位；相机移动必须有跟随、揭示或关系变化的理由。仅有静帧证据时，不能声称原片采用某种轨迹、焦距、速度或升格。

## 风：可播放的最小设计

将风作为环境事件，不只做相机运动。记录世界坐标风向 `wind_dir`、开始/增强/减弱帧和受风资产 ID。布幅固定端和自由端分开；代理可用骨骼、形状键或布料模拟，简单白模不必强求昂贵模拟。头发/衣摆/草木遵守同一主方向，但摆幅、延迟和阻尼不同，避免同相正弦。角色位置与相机不因“有风”自动摇晃。

示例（新设计，24fps、6秒，不是参考实测参数）：帧1–36环境起风；37–72角色察觉、眼/头朝窗；73–120保留反应；121–144落到剧本结果。可选一块窗帘和一处衣摆，固定中景保留脸与窗框；若主节拍是等待来人，帘子只能辅助，不能遮住来人的信息。根据对白和剧情重排帧数。风仅为比喻时使用停顿/距离等关系设计，不创建环境风。

验收：有无明显的受风前后状态；固定端是否漂移；脸和手在关键帧是否可见；同场风向与遮挡是否连续；去掉配乐后是否仍看懂环境变化。幅度、风速与焦距均需本片试拍确定。

## 重逢：可播放的最小设计

为双方分别标记 `see`（看见）、`recognize`（认出）、`respond`（回应）。两人的时点可以不同，观众也可以先知道。镜头数由信息递进决定，不强制四镜模板。

| 分支 | 关系状态与镜头设计 | 白模动作 |
|---|---|---|
| 温暖重逢 | 地理关系→认出反应→间距缩小→接触或共同停留 | A先停步，B抬头，双方才走近；剧本写拥抱时绑定手臂与肩背接触目标 |
| 疏离重逢 | 门框/人流保留边界；反应后仍有双人间距 | A半步前倾后停，B收回视线或不回应；不新增和解 |
| 敌意重逢 | 认出后改变出入口控制或站位，宽景保留退路 | 脚停、身体转向、手势变化与剧本行动相符；不自动加武器 |
| 单方认出/错过 | 用视线与遮挡建立信息差，保留另一人的不知情 | 一人凝视，另一人按原路线离开；未发生相见就不安排双方正反打认出 |

示例（新设计）：旧友在门口看见多年未见的人但没有走近。以同侧行动轴的门框关系景建立两人；近景保留认出后的停顿；回双人景时距离不变，一人移开目光。门、两个人、视线目标和脚步停点足以支撑此段；不需要加雨、花或拥抱。

验收：观众能否指出谁先认出、是否回应以及最后距离；正反打视线高度是否相符；遮挡是否仅延迟信息而非永远藏掉信息；近景是否仍能接回真实站位。

## 分镜与工程记录

在现有分镜/QA中增加一条紧凑记录，不另造重复表格：

`剧本锚点 → 意象原句/上下文 → 语义状态与时间层 → 关系起止 → 主意境/辅意象 → 参考BV+时间码+观察 → 本片设计补充 → 对象/相机/灯光/动作关键帧 → 可见结果 → 失败条件/预览证据`

实现时至少写清：角色起止站位、视线目标、动作触发和结果帧、必要道具接触、相机固定或移动的理由、遮挡对象和显露时点。沿用项目帧率和坐标单位；世界朝向和屏幕方向不能混用。镜头空间不足就调整镜头或调度，不靠穿墙完成路径。

静帧看构图与灰阶；连续预览看识别顺序、布幅、接触和节奏；切点检查目光、动作阶段、道具状态。未渲染只报告“设计已写入”，未播放不能报告运动或情绪效果通过。
