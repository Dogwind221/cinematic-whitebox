# 运镜选择与轨迹设计

## 来源与证据边界

来源：StudioBinder [Ultimate Guide to Camera Movement — Every Camera Movement Technique Explained](https://www.youtube.com/watch?v=IiyBo-qLDeM)，约 29 分钟。2026-09-18 读取原页完整英文字幕，并检查注明原链接的 [B站译制版本](https://www.bilibili.com/video/BV1gt4y1C7YB/)：覆盖全片的 48 张抽帧，以及滚转、环绕、升降和组合段落的 24 张连续时刻抽帧。镜像未做逐帧同一性校验；时间码以原片章节为索引。抽帧不证明连续运动的速度、平滑度或无剪辑；组合段落含多个镜头。

下表为课程归纳；后面的参数、实现与验收方法为面向白模的工程推导。保留《繁花》主风格，按当前节拍选用，不要求遍历全部运镜。

## 先选叙事作用，再选变化通道

| 原片章节 | 适用的叙事问题 | 白模中实际改变什么及易混点 |
|---|---|---|
| 01:18 固定 | 让表演主导、等待、旁观或困住人物 | 相机固定，变化交给调度；固定不等于情绪中性 |
| 03:12 摇摄；03:55 甩镜 | 跟视线、逐步揭示，或迅速连接两方 | 固定机位改变水平朝向；甩镜是快速转向，不能用横移代替 |
| 05:11 俯仰 | 仰望规模、从物件揭示人物或反向扫描 | 改变上下朝向；相机本身不必升降 |
| 07:07 推近；09:05 拉远 | 接近思想/决定，或揭示环境、疏离与结束 | 相机位置靠近/离开；先确定新增信息，避免台词一开始就自动推近 |
| 10:24 变焦；11:55 急变焦 | 光学强调、观察感、突发发现或喜剧重音 | 改焦距而非机位；与推近的透视和视差不同，数码裁切也不等同于镜头参数变化 |
| 12:50 滑动变焦 | 认知改变、压力，也可表达连接和亲近 | 位移与反向焦距变化协同，维持目标大小；不要限定为恐惧效果 |
| 15:36 滚转 | 失衡、权力反转、方向感变化 | 围绕相机光轴转动；不是围绕人物绕行，也不是固定倾斜构图 |
| 17:43 跟拍；19:25 横移 | 陪伴行动、悬念目的地、沿途揭示空间关系 | 跟拍描述与主体的关系，横移描述路径，两者可重叠；明确实际路径和相对位置 |
| 20:40 环绕 | 重组人物关系、形成合力、紧张或亲密 | 相机围绕枢轴移动并调整朝向；按揭示需求选弧度，无需完整 360° |
| 22:47 升降 | 揭示上下空间、阻碍或状态变化 | 改相机高度并独立设计朝向；机械摇臂可能走弧线，不必强行模拟为竖直直线 |
| 24:23 不规则运动 | 主观慌乱、纪实感、人物状态对照 | 在有意的基础路径上加入受控扰动；随意逐帧跳动不能代替手持感 |
| 26:27 场景练习 | 同一场景按信息变化组织多种运动 | 区分镜头之间的选择与同一镜头内的复合运动，不把示范拼接误读为一个长镜头 |

相同手法可能产生不同意义。课程中的甩镜既组织音乐互动也组织对抗；滑动变焦也可拉近人物与观众的关系。先写明当前剧情依据，再选择形式。固定镜头能完成任务时，保留固定版本比较。

## 把运动写成可执行事件

在现有分镜的“时间/摄影/验收”字段内补记以下内容，不另造一套重复表格：

- **触发与信息**：对白、动作或发现发生在哪一帧；运动前观众知道什么，结束后新增什么。
- **通道**：基础位置路径、朝向目标、光轴滚转、焦距和焦点分别如何变化；同时记录主体路径及相机相对主体的距离。
- **时间**：启动、加速、峰值、减速、停住和结果停留；只记录实际存在的阶段，速度由节拍和画面决定。
- **接口**：结束构图、焦点归属、下一镜的屏幕方向和切点；是否需要留出剪辑余量。

例如剧本中的人物听见门外响动：可先固定让反应出现，再摇向门口揭示来者，停住让身份可读。只有突发强度与前后节奏支持时才改为甩镜；不为使用课程术语强加惊吓。

## 用显式字段声明运镜，不要靠坐标差暗示

把运镜写成两个三维点（`loc_a`→`loc_b`）的坐标差是常见做法，但它只是**位置端点**，不表达意图：0.14 m 的漂移与 0.75 m 的推进在数据上长得一样，读者看不出这是「推进」「横移」还是「没写」。结果是该推的镜头没人推、随机漂移被当成运镜，验收时也无法判断位移是否达到可读量级。

因此在分镜里显式声明 `move`，由解算器换算成端点位移（参考实现：`agents/camera_motion.py`）：

```
move = {'type': 'dolly', 'distance': 0.35, 'ease': 'inout', 'framing': 'auto'}
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `type` | `dolly` | 沿光轴推进（正）/ 拉远（负）。**最常用**，对应课程 07:07 推近、09:05 拉远 |
| | `truck` | 横移，正值向画面右。对应 19:25 |
| | `pedestal` | 升降，正值升高。对应 22:47 |
| | `arc` | 围绕注视点环绕，用 `angle`（度）。对应 20:40 |
| | `zoom` | 只改焦距（不改位姿），`distance` 为焦距增量 mm。对应 10:24 变焦 |
| | `static` | 显式固定机位，便于校验。对应 01:18 |
| `distance` | 米（`zoom` 为 mm） | 位移量。**低于 0.06 m 视为没有运镜** |
| `ease` | `inout`（默认） | 两端缓。情绪压迫用 `in`，突袭用 `out`，机械匀速用 `linear` |
| `framing` | `'auto'`（默认） | 按初始视线的余弦比例补偿注视点：主体留在原本的画框位置 |
| | `0.0` | 不补偿：保留初始视差，但机位前移后主体可能被挤出画框、近处前景占满画面 |
| | `0.5` | 半程补偿 |
| | `1.0` | 注视点与机位同步平移：构图完全锁定，主体留在原位 |
| `sync_aim` | `false`（默认） | `true` 时注视点跟随机位，主体不放大，只有视差变化（跟拍） |

四点容易搞错：

1. **推进 ≠ 把 `loc_b` 写近一点**。推进是沿「机位→注视点」光轴前进，与主体的距离真的变小，画面整体向外扩散；`zoom` 只改焦距，两者的透视和视差不同（课程 12:50 滑动变焦正是让二者反向）。
2. **`framing` 不改变放大倍率**。机位终点由 `move` 决定，主体到机位的距离因而固定：放大倍率＝起始距离÷终点距离，与 `framing` 无关。`framing` 只决定主体落在画框内的**位置**。所以 `0.0` 与 `1.0` 的放大完全相同，差别是构图还能不能用——0.0 时主体可能已经出框。不要把它当成「调放大」的旋钮。
3. **放大倍率必须用主体点度量**，不能用注视点。注视点已被 `framing` 补偿前移，用它算距离会把推进误报成几乎没动：0.35 m 推进用注视点算只有 1.04×，用主体算才是 1.20×。参考实现的 `verify_motion(sub, subject=...)` 就是为此提供 `subject` 参数。
4. **长焦 + 近距前景时，位移必须小**。前景物件到机位的距离远小于主体，同样的机位位移会让前景放大数倍并挤入画面中心。90 mm、前景约 1 m 的镜头，推进量取 0.25–0.45 m 通常已能读出推进而不失衡。

解算后必须核对三项，并写进分镜元数据以便复查：

- **到位移**：`path_m` 是否达到可读量级（推进一般 ≥0.25 m，近景特写 ≥0.35 m）
- **主体是否单调靠近**：`approach_monotonic`；放大倍率 `scale` 是否 >1.1
- **构图是否保持**：`aim_shift_m` 与 `framing` 记录补偿了多少；必要时逐帧看主体是否还在画框内

参考实现的 `verify_motion()` 会直接返回 `path_m / aim_shift_m / framing / scale / approach_monotonic / effective`，`dp_build.py` 则把同样的结果写成分镜元数据的 `motion` 字段：

```
'motion': {'type': 'dolly', 'path_m': 0.35, 'ease': 'inout', 'framing': 0.8, 'sync_aim': False,
           'declared': {...}, 'resolved': {'loc_a': [...], 'loc_b': [...], 'lens_zoom': 1.0},
           'resolved_aim': {'aim_a': [...], 'aim_b': [...], 'framing': 0.8}}
```

**判据示例**（L6 庭院茶席 DP02，90 mm，主体距机位 2.09 m，推进 0.35 m）：

| 配置 | 位移 | 主体放大 | 结论 |
|---|---|---|---|
| 未声明 `move`（原设计的隐式漂移） | 0.145 m | 1.072× | 漂移，读不出运镜 |
| `framing: 0.0` | 0.35 m | 1.201× | 放大相同，但主体有被前景挤出画框的风险 |
| **`framing: 'auto'`（折算 0.80）** | **0.35 m** | **1.201×** | 采用：放大不变，构图稳住 |
| `framing: 1.0` | 0.35 m | 1.201× | 放大同样不变，构图完全锁定（补偿最多） |

注意上表中间三行的**放大完全相同**——这正是第 2 点的意思：想改变放大要改 `distance`，不是改 `framing`。

数据与画面必须同时成立，不能只凭字段存在就宣称运镜成立。

## 需要特别处理的实现

1. **滚转**：先形成基础路径与瞄准，再叠加局部光轴旋转。检查瞄准约束是否覆盖滚转，以及插值是否跨角度边界突翻；地平线变化必须对应预定节拍。
2. **环绕**：记录枢轴、半径、起止角、高度和瞄准目标；人物移动时明确枢轴是否跟随。沿弧检查前景遮挡、脸部朝向及屏幕左右关系。跨轴需让观众看懂过渡；运动停住可对应关系或判断的改变。
3. **升降与跟随**：升降独立控制机位高度和俯仰；跟拍检查主体速度、相对偏移及屏幕占比。场景净空、天花板、门框和地面都参与路径检查，不能为追上角色穿墙。
4. **甩镜与急变焦**：分别设计转向速度和焦距变化速度；先确定落点和停留，再设计中间加速。模糊取决于实际渲染曝光设置，不能借拖影掩盖错误落点。没有配乐时不宣称已完成音乐同步。
5. **手持扰动**：先验证基本路径，再用可重复的平滑扰动叠加位置/朝向；保存种子或烘焙关键帧，限定幅度和频率。始终保留脸、动作接触点和关键物件的可读性，不独立给每帧任意位置。
6. **滑动变焦**：复用 [导演手法选择](director-routing.md) 的投影关系。固定传感器条件下，以目标大小近似取决于焦距/距离来配对；机位靠近时减小焦距，远离时增大焦距。背景变化须实际投影复检，不直接搬用口头描述推断方向；倾斜、遮挡和目标姿态会影响匹配。
7. **复合运动**：分别设计位置、瞄准、滚转、焦距和焦点，再放在共同时间轴上合成。每个通道都要有作用，避免单独平滑但组合后突然加速或焦点漂移；镜头间剪辑不算单镜内部复合运动。

## 与《繁花》主风格结合及验收

默认仍用框景、人物关系、光影和情绪停留组织镜头。审视与犹豫可固定或缓推；关系揭示可横移/小弧度环绕；强烈失衡才考虑滚转或明显扰动。选择依据来自剧本，不按题材自动分配。

允许在同一场景中有动机地对照稳定与不稳定视角，例如冷静者与慌乱者，但须注明视点或状态变化，并维持空间与时间连续。课程《七宗罪》例子支持这种局部对照，不意味着每句对白随机换摄影逻辑。

除首中尾帧外，检查触发、速度峰值、信息揭示、停止和切点附近画面；确认信息没有提前泄露，停止后有足够可读时间。按实际输出帧率播放渲染，检查轨迹、朝向、焦点及运动模糊的组合结果。参数存在、静帧通过或抽帧序列均不能单独证明运镜流畅。未渲染时只报告设计完成。
